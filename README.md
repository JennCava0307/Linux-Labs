# Linux & DevOps Labs

A collection of hands-on Linux command-line labs and practical administrative exercises.

## Completed Labs & Exercises

* **Lab 1: Introduction to Linux**
  * Overview of the Linux operating system, architecture, and core philosophy.
  * Understanding the command-line interface (CLI) vs. graphical user interfaces (GUI).

* **Lab 2: Listing & Inspecting Files (`ls`)**
  * Practiced using `ls` with various flags (`-l`, `-a`, `-R`, `-Al`) to view file permissions, hidden files, and recursive structures.
  * Learned to filter listings using wildcards (e.g., `*.tmp`).

* **Lab 3: Directory Management**
  * Navigated the filesystem using `pwd` and `cd`.
  * Created parent directories and nested folder structures efficiently using `mkdir -p`.

* **Lab 4: File Operations & Troubleshooting**
  * Created zero-byte files using `touch`.
  * Managed file and directory deletions safely using `rm` and recursive/force deletion (`rm -rf`).
  * Troubleshot automated lab verification errors (differentiating between directory containers and empty marker files like `.processed`).
